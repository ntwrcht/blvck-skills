Produces a product requirements document with problem, solution, success metrics, user stories, and out-of-scope sections, then shows the exact tracker payload — title, body, labels, and target — and asks for the user's approval before creating anything. It does not create or claim to have created a tracker issue. The User Stories section holds between three and eight numbered stories that bound the feature, with no acceptance criteria, task breakdowns, or estimates attached to them.
