Produces a product requirements document containing, as headings or clearly labelled sections: a problem statement, a solution, success metrics, user stories, and an out-of-scope section. Every success-metric baseline or target the prompt does not supply is written as UNKNOWN rather than estimated or invented. The User Stories section holds between three and eight numbered stories that bound the feature, with no acceptance criteria, task breakdowns, or estimates attached to them.
