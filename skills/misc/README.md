# Misc Skills

Skills kept around but rarely used.

| Skill Name | Description |
| :--- | :--- |
| [Caveman](caveman/SKILL.md) | Ultra-compressed communication mode that drops filler, articles, and pleasantries while keeping technical accuracy. Use when the user says caveman mode, talk like caveman, use caveman, less tokens, be brief, terse mode, or invokes /caveman. |
| [Git Guardrails](git-guardrails/SKILL.md) | Installs Claude Code PreToolUse hooks that block dangerous git commands before execution. Use when setting up local or global guardrails for git push, force push, reset --hard, clean, branch deletion, checkout ., or restore . |
| [Wait, What](wait-what/SKILL.md) | Re-pitches the message that just failed to land, adding the missing context and dropping the jargon. Use when a reply lost the reader through unexplained jargon, a skipped step, or missing context; the user runs it with /wait-what. |
